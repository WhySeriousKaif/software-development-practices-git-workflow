About This Project

This project was created as part of my Software Development Practices assignment.

The purpose of the project is to learn how Git tracks changes and how a local repository can be connected to GitHub.

Topics Demonstrated

  • Creating a local Git repository
  • Making multiple commits
  • Working with branches
  • Merging a feature branch
  • Undoing a commit
  • Pushing a repository to GitHub

Benefits of Version Control

Version control helps developers track changes, work safely with branches, and maintain a clear history of a project.
