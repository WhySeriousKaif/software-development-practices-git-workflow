GIT COMMANDS USED IN THE ASSIGNMENT

1. git init
Initializes a new local Git repository in the current project folder.

2. git branch -M main
Renames the current default branch to main.

3. git status
Displays the current branch and the state of tracked, modified, staged, and untracked files.

4. git config user.name
Displays the username currently configured for Git commits.

5. git config user.email
Displays the email address currently configured for Git commits.

6. git add index.html about.html
Stages index.html and about.html for the initial commit.

7. git commit -m "Add initial website pages"
Records the initial version of the two website pages.

8. git log --oneline
Displays the commit history in a compact one-line format.

9. git diff
Displays unstaged changes made to the project files.

10. git add index.html
Stages the modified home page for the second commit.

11. git commit -m "Add project goals to home page"
Records the new project-goals section in the repository history.

12. git log --oneline --decorate
Displays compact history with branch and HEAD labels.

13. git branch feature
Creates a new branch named feature.

14. git switch feature
Changes the active working branch from main to feature.

15. git branch
Lists the local branches and marks the active branch with an asterisk.

16. git add index.html about.html
Stages the changes made while working on the feature branch.

17. git commit -m "Add version control benefits on feature branch"
Records the feature-branch changes as a separate commit.

18. git log --oneline --decorate --graph --all
Displays a graphical history containing every branch and its commits.

19. git switch main
Changes the active branch back to main.

20. git merge --no-ff feature -m "Merge feature branch into main"
Merges feature into main and creates an explicit merge commit.

21. git status --ignored
Displays normal repository status along with files excluded by .gitignore.

22. git add .gitignore
Stages the .gitignore file.

23. git commit -m "Add Git ignore rules"
Records the ignore rules for .log files and the temp folder.

24. git add index.html
Stages the temporary change made to index.html.

25. git commit -m "Add temporary demonstration message"
Creates an additional commit for demonstrating the undo operation.

26. git revert --no-edit HEAD
Safely reverses the latest commit by creating a new revert commit.

27. git show --stat --oneline HEAD
Displays a short summary and file statistics for the latest commit.

28. git add git_commands.txt
Stages the Git command documentation file.

29. git commit -m "Add Git command documentation"
Records the command documentation in the repository history.

30. git add git_commands.txt
Stages the corrections made to the Git command documentation.

31. git commit -m "Correct Git command documentation"
Records the corrected Git command descriptions.

32. git remote add origin https://github.com/WhySeriousKaif/software-development-practices-git-workflow.git
Connects the local repository to the public GitHub repository using the name origin.

33. git remote -v
Displays the fetch and push URLs configured for the remote repository.

34. git push -u origin main
Uploads the main branch and its complete commit history to GitHub and configures upstream tracking.

35. git push -u origin feature
Uploads the feature branch to GitHub and configures its upstream tracking.

36. git branch -vv
Displays local branches together with their latest commits and remote tracking branches.

37. git add git_commands.txt
Stages the final GitHub command documentation.

38. git commit -m "Document GitHub integration commands"
Records the completed GitHub command documentation.

39. git push origin main
Uploads the final documentation commit to the main branch on GitHub.
